# Chapter One: Two Pointers

## Getting Started 🚀
The following problems are located in the subfolder two-pointers.

- Leetcode 125: [Valid Palindrome](https://leetcode.com/problems/valid-palindrome/description/)
- Leetcode 167: [Two Sum II - Input Array is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/description/)

1. Read the README.md located in the folder that corresponds to the problem in the above list.
2. Attempt to solve the problem yourself. The solution is located in main.go
3. Read the EXPLANATION.md. It provides the why behind how the solution in main.go works.
4. Validate the module tests. Run <code>go test -v</code> in the problem directory.
