# Coding Interview Patterns

![Go](https://img.shields.io/badge/Go-00ADD8?logo=Go&logoColor=white&style=for-the-badge)

## Purpose
To provide a series of solutions in Go based on the problems in Alex Xu & Shaun Gunawardane's book *Coding Interview Patterns*. 

Actual problems are taken from Leetcode and Hacker Rank. The solutions contained within should assist you with the problems in the book.
